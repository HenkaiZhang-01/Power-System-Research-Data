# Power System Research Data

This repository provides the datasets supporting the research findings presented in our manuscript.

## Dataset Description

The repository contains four CSV files:

- `load_33bus_month_15min.csv`: Load time-series data for the 33-bus system.
- `load_118bus_month_15min.csv`: Load time-series data for the 118-bus system.
- `pv_33bus_month_15min.csv`: Photovoltaic generation time-series data for the 33-bus system.
- `pv_118bus_month_15min.csv`: Photovoltaic generation time-series data for the 118-bus system.

## Data Availability

The datasets are publicly accessible through this GitHub repository.

## Data Usage

The datasets are provided to support academic research, numerical simulations, and reproducibility of the reported results.
